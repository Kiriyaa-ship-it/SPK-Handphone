# PROJECT BRIEF

## Sistem Pendukung Keputusan Pemilihan Handphone

### 1. Informasi Proyek

Nama Proyek: Sistem Pendukung Keputusan Pemilihan Handphone

Jenis Aplikasi: Website

Mata Kuliah: Teamwork Building

Metode Pengambilan Keputusan: Simple Additive Weighting (SAW)

### 2. Latar Belakang

Banyaknya pilihan handphone dengan spesifikasi dan harga yang berbeda membuat pengguna terkadang kesulitan menentukan perangkat yang sesuai dengan kebutuhan dan anggaran mereka.

Oleh karena itu, proyek ini bertujuan mengembangkan sebuah sistem pendukung keputusan berbasis website yang dapat membantu pengguna memperoleh rekomendasi handphone berdasarkan kebutuhan, prioritas, dan batas anggaran.

### 3. Tujuan Sistem

Membantu pengguna memilih handphone berdasarkan beberapa kriteria penilaian dengan menggunakan metode SAW.

### 4. Target Pengguna

* Pengguna yang ingin membeli handphone.
* Pengguna dengan anggaran terbatas.
* Pengguna yang memiliki kebutuhan khusus seperti gaming, fotografi, dan penggunaan sehari-hari.

### 5. Teknologi

Frontend:

* HTML
* CSS
* JavaScript

Backend:

* PHP

Database:

* MariaDB/MySQL

Local Development:

* XAMPP

Version Control:

* Git dan GitHub

### 6. Fitur Utama

1. Menampilkan daftar handphone.
2. Memasukkan anggaran pengguna.
3. Memilih kebutuhan dan prioritas.
4. Menyaring handphone berdasarkan anggaran.
5. Menghitung rekomendasi menggunakan metode SAW.
6. Menampilkan hasil rekomendasi berdasarkan peringkat.
7. Menampilkan detail spesifikasi handphone.
8. Membandingkan beberapa handphone.

### 7. Batasan Pengembangan

* Sistem berbentuk website.
* Pengembangan menggunakan PHP native.
* Database menggunakan MariaDB/MySQL.
* Metode pengambilan keputusan menggunakan SAW.
* Sistem dikembangkan secara bertahap.
* Fitur tambahan dapat dikembangkan setelah fitur utama berjalan.

### 8. Prinsip Pengembangan

* Mengutamakan kode yang mudah dipahami dan dipelihara.
* Menggunakan struktur proyek yang terorganisasi.
* Menghindari fitur yang tidak diperlukan.
* Setiap perubahan harus dapat diuji.
* Keputusan arsitektur harus didokumentasikan.
* AI Agent berfungsi sebagai asisten pengembangan, bukan pengambil keputusan utama.
* Perubahan penting harus mendapatkan persetujuan Project Lead.
